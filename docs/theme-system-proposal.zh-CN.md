# OpenTypora 主题系统方案（提案）

> 状态：设计稿 · 待确认后实施
> 核心理念：**我们只做好框架，主题的「生产」交给用户和他们的 AI。**

## 一、设计原则

1. **框架优先，内置从简**。官方只维护 6 套内置主题（现有 5 套 + auto）。主题的丰富度靠生态，不靠官方堆人力。
2. **主题 = 数据，不是代码**。主题用一份带 schema 的 JSON 描述（CSS 变量覆盖），禁止执行任意逻辑，天然安全、可校验、可被 AI 生成。
3. **AI 原生**。用户在 AI 面板填自己的 API Key（现有能力，兼容 OpenAI/Ollama/LM Studio），说一句「给我一个护眼墨绿色的暗色主题」，AI 按 schema 生成 → 实时预览 → 一键保存。我们不提供、不代理、不收费任何模型服务。
4. **借力 Typora 生态**。提供 Typora `.css` 主题的导入转换器——Typora 有上百套社区主题，让它的生态成为我们的启动生态。

## 二、主题格式（.ot-theme.json）

```json
{
  "name": "墨绿护眼",
  "author": "someone",
  "tone": "dark",
  "base": "dark",
  "vars": {
    "--bg": "#0f1c17",
    "--fg": "#d7e4dc",
    "--accent": "#4ac28f",
    "--code-bg": "#14251e",
    "--font-content": ""
  },
  "css": "/* 可选：受控的补充样式，只作用于编辑器容器内 */"
}
```

- `vars` 只允许白名单键（现有 ~17 个 CSS 变量），颜色值做格式校验；
- `css` 字段可选，注入时强制加 `#editor` 前缀作用域 + CSP 友好处理；
- `tone` 决定代码高亮配色与 Mermaid 明暗；
- 同一格式既用于本地导入，也用于在线主题库分发。

## 三、三层来源

| 层 | 来源 | 实现方式 |
|---|---|---|
| 内置 | 仓库内 `themes/builtin/` | 现有 CSS 变量体系迁移为同格式 JSON，统一渲染管线 |
| 本地 | 用户导入 `.ot-theme.json` / Typora `.css` | File System Access 打开 → 校验/转换 → 存 IndexedDB → 出现在主题菜单 |
| 在线 | GitHub 仓库 `themes/gallery/` 目录 | 主题菜单里的「浏览主题库」拉取目录列表（走 GitHub raw），点击即装；社区通过 PR 投稿 |

## 四、AI 生成主题流程（复用现有 BYO-key AI 面板）

```
用户：「我想要一个低饱和度暖色纸质主题，正文衬线字体」
  ↓
组装 Prompt = 变量白名单 + 语义说明（每个变量管什么）+ 用户描述 + 当前主题作为参照
  ↓
调用用户已配置的 API（OpenAI 兼容，本地 Ollama 亦可）
  ↓
解析响应 → 校验 JSON → 立即应用为「预览主题」（右上角浮条：保存 / 撤销）
  ↓
保存 → 写入 IndexedDB 用户主题列表，可再导出为 .ot-theme.json 分享
```

关键点：**Prompt 模板与变量语义表本身就是公开文档**（`docs/theme-schema.md`），所以任何模型、任何用户都能离线生成主题；这也是社区教程的素材。失败（模型输出不合法）就回退并展示原因，可一键重试。

## 五、Typora 主题兼容转换器

Typora 主题是 `.css` 文件，其中大量规则命中我们同名的 CSS 变量与选择器约定。转换器做三件事：

1. 提取 `:root` / `body` / `#write` 下的颜色与字体声明，映射到我们的变量白名单；
2. 无法映射的规则降级进受控 `css` 字段（仍限定作用域）；
3. 输出标准 `.ot-theme.json`，标记 `convertedFrom: "typora"`。

迁移叙事对营销极有价值：「你喜欢的 Typora 主题，拖进来就能用」。

## 六、安全边界

- JSON 主题：键白名单 + 颜色/字体值正则校验，无脚本执行面；
- `css` 字段：注入前移除 `@import`/`url(http…)`（防外联追踪）、强制 `#editor` 作用域；
- 在线主题库只从本仓库 GitHub raw 拉取，附作者与 PR 记录，可审计；
- 用户主题存 IndexedDB，不进文档、不外传。

## 七、实施计划（预计 3 个批次）

| 批次 | 内容 | 工作量 |
|---|---|---|
| T1 | 主题格式 + 内置主题迁移 + 本地导入/管理 UI + 用户主题持久化 | 1 个批次 |
| T2 | AI 生成器（prompt 组装、校验、预览浮条）+ `docs/theme-schema.md` | 1 个批次 |
| T3 | 在线主题库（gallery 目录 + 浏览/一键安装 + PR 模板）+ Typora 转换器 | 1 个批次 |

## 八、验收标准

- 用户无需懂 CSS 即可通过 AI 得到可用主题；
- Typora 热门主题（Newsprint、Drake 等）转换后可正常使用；
- 主题安装/切换零刷新（现有 refreshDecos 机制已支持热切换）；
- 离线环境（本地 Ollama）全流程可用。
